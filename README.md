Input Format (For Users)
1. Enter Number of Consumers
Example: 3
2. For Each Consumer, Provide Inputs
A. Consumer ID (string)
Example: C1001
B. Units Consumed (integer)
Example: 450
C. Connection Type (1 = Domestic, 2 = Commercial)
Example: 1 → Domestic, 2 → Commercial
Example Full Input:
Enter number of consumers:
2
Enter Consumer ID: C101
Enter Units Consumed: 350
Enter Connection Type: 1
Enter Consumer ID: C102
Enter Units Consumed: 680
Enter Connection Type: 2
Notes:- Only 1 or 2 is allowed for connection type.- Units must be a positive integer.- ConsumerID can be any string
